Proyek

Aplikasi Survey

Aplikasi Survey adalah aplikasi untuk membuat dan mengelola survei secara efisien. Dibuat menggunakan Laravel Lumen sebagai backend dan Vue.js sebagai frontend.

Website Masjid

Website Masjid adalah aplikasi pencatatan sumbangan pembangunan masjid, mencatat siapa yang menyumbang, jumlah, dan jenis sumbangan. Dibuat dengan PHP, CSS, dan JavaScript.

Apotek Website

Apotek Website adalah aplikasi untuk mengelola data obat, stok, dan transaksi penjualan. Dibuat menggunakan Laravel, Bootstrap, dan JavaScript untuk tampilan dan fungsionalitas yang responsif.

School-Track

School-Track adalah aplikasi untuk mengelola tagihan sekolah seperti SPP dan semester, serta menyediakan fitur pembelajaran online. Dibuat menggunakan Laravel API dan React.

Point Kasir

Aplikasi Kasir / Point Kasir adalah web aplikasi untuk mengelola data produk dan penjualan, serta mendukung pembayaran menggunakan poin member. Dibuat dengan Laravel, Bootstrap, dan JavaScript.
